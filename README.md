# vcaa-ig-publicadas
Imágenes ya aprobadas de @vcaa_inmobiliaria_e_inversion. Las sube FDiseg (vcaa-contenido) minutos antes de publicarlas en Instagram.

`publicadas.json` lista los últimos posts del feed (enlace, fecha, tema, alt y portada) para la franja «Síguenos en
Instagram» de vcaa.cl. Lo actualiza «Publicar» después de cada publicación (`scripts/publicadas.mjs`).
